# Path of Titans ダメージ計算機（試作）

## ローカルでの起動
`index.html` を直接開くと、ブラウザのセキュリティ制限で `dinosaurs.json` が読み込めない場合があります。
フォルダ内でローカルサーバーを起動してください。

Pythonがある場合:
```bash
python -m http.server 8000
```
ブラウザで http://localhost:8000 を開きます。

## GitHub Pagesで公開
1. GitHubで新しいPublicリポジトリを作成
2. このフォルダ内の4ファイル（index.html, style.css, app.js, dinosaurs.json）をアップロード
3. Settings → Pages → Deploy from a branch → main / root を選択
4. 表示されるURLでアクセス

## 注意
- 登録値はユーザー提供のWiki表を転記した初期値です。現行ゲーム内の正確性を保証するものではありません。
- 「鎧」列はWiki値として表示用に保持しています。装甲値入力の初期値には適用せず、入力欄は0%です。
- イグアノドンの基本攻撃力は提示表が32/40/48のため、初期値40にしています。
- 出血・毒・骨折・ピアス等の追加効果は、現段階の直接ダメージ計算には含めていません。
- 基本式は会話で合意した体重比×攻撃力に、被弾部位倍率と装甲軽減を適用する仮モデルです。実ゲームと照合して調整してください。


v2変更点：HP・体重・Wiki鎧値も個別編集可能。Wiki鎧値は参考値で計算には直接使用しません。装甲軽減倍率は初期値1.00（軽減なし）で、25%軽減なら0.75を入力します。個別倍率の初期値は0.00です。
